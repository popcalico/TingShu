# 听评书 · 项目文档

本目录是给**下一位接手的人（或 AI）**看的。按下面的顺序读，20 分钟能完整接手。

| 文件 | 内容 | 什么时候读 |
|---|---|---|
| [00-AI接手须知.md](./00-AI接手须知.md) | 5 分钟速览：项目是什么、现在到哪一步、下一步做什么、有哪些坑不能踩 | **第一个读这个** |
| [01-工作日志.md](./01-工作日志.md) | 按时间顺序的完整工作日志：每个动作的目的是什么、执行了什么、结果如何、遇到什么错、怎么解决的 | 要理解"为什么代码是现在这样"时读 |
| [02-环境与构建.md](./02-环境与构建.md) | 本机工具链路径、环境变量、代理、构建命令、工具链版本约束 | 要编译/打包/换机器时读 |
| [03-技术决策记录.md](./03-技术决策记录.md) | 每个关键技术选择的背景、备选方案、取舍理由（ADR 格式） | 想改动架构之前读，避免推翻已经踩过坑的结论 |
| [04-故障排查手册.md](./04-故障排查手册.md) | 按"症状 → 原因 → 处理"组织的排错索引，含本次构建踩过的 9 个坑的原始报错 | 构建失败或功能异常时查 |
| [05-待办与风险.md](./05-待办与风险.md) | 未完成项、已知缺陷、外部依赖风险（夸克/B站接口） | 继续开发前读 |
| [06-自动更新与服务器配置.md](./06-自动更新与服务器配置.md) | 阿里云怎么配合：目录、Nginx、版本号规则、发布脚本、带宽坑 | 要发布新版本时读 |
| [07-模拟器测试.md](./07-模拟器测试.md) | Android Studio 模拟器怎么跑、能测什么、测不了什么 | 要在电脑上调试时读 |
| [08-预缓存方案.md](./08-预缓存方案.md) | 从 NAS/网盘批量入库的方案：连 NAS 选型、文件识别规则、容量策略、实施计划 | **做预缓存功能前必读**（尚未开发） |

## 文档约定

- 时间一律用本机时间（GMT+8），格式 `HH:MM`。
- 命令一律照抄可执行，路径用绝对路径。
- 报错原文用代码块保留，不做美化——下一个排查的人需要能搜到同样的字符串。
- 结论要写"为什么"，不只写"是什么"。踩过的坑必须记录**当时的错误猜测**，避免下一任重复试错。
