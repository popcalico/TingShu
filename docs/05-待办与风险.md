## 四、风险登记

### R1 夸克接口无官方支持（等级：中高）

- **描述**：用的是网页版逆向接口（与 OpenList 驱动一致）。夸克调整风控、改路径、加签名时，App 会直接失效。
- **影响**：夸克源完全不可用。
- **影响面控制**：所有夸克相关代码集中在 `lib/services/quark/`，接口变更只需改 `quark_api.dart` 一个文件。
- **缓解**：保留 B 站评书源作为备用源（设置页可切换）。
- **需要监控**：`/file/sort` 返回 `code != 0`、`/file/download` 拿不到 `download_url`、响应里出现新的 `_sign`/`_timestamp` 参数（说明加了签名）。

### R2 libmpv jar 依赖手动放置（等级：中）

- **描述**：`flutter clean` 会删除 `build/media_kit_libs_android_audio/v1.1.8/*.jar`，下次构建会卡在 GitHub 下载超时。
- **缓解**：已写进 [02-环境与构建 §5](./02-环境与构建.md#flutter-clean-之后必须补的一步)，提供一键补下载脚本。
- **根治方向**：把 4 个 jar 提交到工程内的 `android/app/libs/` 并在 `build.gradle.kts` 里 `implementation(files(...))` 覆盖；或改用 `just_audio`（走 ExoPlayer，无 native 下载）。

### R3 Cookie 会过期（等级：中）

- **描述**：夸克登录态通常保持数周到数月。
- **用户体感**：某天打开提示"登录已过期，请家属重新登录"。
- **已做的**：`QuarkException.needLogin` 会把 401/31001/31023 映射成明确文案；设置页显示连接状态。
- **未做的**：过期主动提醒（可在启动时静默探测一次，失败则在首页显示一条黄色提示）。

### R4 B 站风控（等级：中）

- **描述**：`-412`（请求被拦截）、`-352`（风控校验失败）随时可能因请求节奏、IP 而触发。
- **已做的**：沿用原工程的 450ms 请求间隔、WBI 签名、buvid 激活、指数退避重试。
- **注意**：**不要**缩短 `BiliClient._minGapMillis`，也不要并发发起搜索请求。

### R5 版权与合规（等级：需用户知晓）

- 内容来自用户自己的网盘与 B 站公开视频，App 不存储、不分发内容。
- 交付说明里已写明"仅供个人收听，请勿二次分发"。
- 不上架应用商店（含 B 站内容 + 逆向接口，过审不可能），只做侧载安装。

### R6 签名丢失（等级：高，人为）

- `android/app/tingshu-release.jks` 与密码 `见本机 android/key.properties（不入库）` 一旦丢失，无法覆盖升级。
- 已写进 [02-环境与构建 §6](./02-环境与构建.md#6-签名)。**提醒用户备份。**
